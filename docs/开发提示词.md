# 开发提示词

这个文件保留了 DeskStickyNotes 初版开发时使用的 AI 提示词。项目的初始代码、UI、文档和打包流程由 AI 辅助生成，并经过本地构建和手动验证。

---

请使用 C# WPF + .NET 开发一个 Windows 11 桌面便签软件，要求如下：

项目名称：DeskStickyNotes

核心目标：
做一个类似 Windows 7 桌面便签的软件，但适配 Windows 11。便签窗口不显示在任务栏，只通过系统托盘图标管理。

功能要求：

1. 便签窗口
- 支持创建多个便签。
- 每个便签是独立窗口。
- 窗口无标准标题栏，但需要有简洁的顶部拖动区域。
- 支持拖动位置。
- 支持调整大小。
- 支持编辑文本内容。
- 支持删除当前便签。
- 支持最小化/隐藏当前便签。
- 支持每个便签单独设置 Always On Top。
- 便签窗口不要显示在 Windows 任务栏。

2. 系统托盘
- 程序启动后在右下角系统托盘显示图标。
- 右键托盘图标显示菜单：
  - New Note
  - Show All Notes
  - Hide All Notes
  - Settings
  - Exit
- 双击托盘图标新建一个便签。

3. 数据保存
- 自动保存所有便签。
- 保存内容包括：
  - id
  - text content
  - x / y position
  - width / height
  - color
  - topmost
  - visible
  - updatedAt
- 数据保存到用户 AppData 目录，例如：
  %AppData%/DeskStickyNotes/notes.json
- 程序启动时自动恢复上次的便签状态。

4. 开机自启
- 在设置界面中提供开关。
- 开启后写入 Windows Startup Registry：
  HKCU\Software\Microsoft\Windows\CurrentVersion\Run
- 关闭后移除该启动项。

5. 设置界面
- 支持默认便签颜色。
- 支持默认字体大小。
- 支持是否开机自启。
- 支持默认是否置顶。
- 支持自动保存间隔，例如 2 秒。

6. UI 要求
- 风格简洁，适合 Windows 11。
- 便签默认颜色为浅黄色。
- 便签可以切换颜色：
  - Yellow
  - Green
  - Blue
  - Pink
  - White
- 便签内容区域使用 TextBox。
- 顶部栏包含：
  - 颜色按钮
  - 置顶按钮
  - 删除按钮
  - 隐藏按钮

7. 工程要求
- 使用 MVVM 结构。
- 代码结构清晰：
  - Models/NoteModel.cs
  - Services/NoteStorageService.cs
  - Services/TrayService.cs
  - Services/StartupService.cs
  - ViewModels/NoteViewModel.cs
  - Views/NoteWindow.xaml
  - Views/SettingsWindow.xaml
  - App.xaml.cs
- 不要依赖大型第三方框架。
- 可以使用 Newtonsoft.Json 或 System.Text.Json。
- 托盘图标可以使用 System.Windows.Forms.NotifyIcon。
- 请提供完整可运行代码。
- 请提供 README.md，说明如何运行、打包、发布 exe。

额外要求：
- 所有便签窗口必须设置 ShowInTaskbar = false。
- 退出程序前必须保存所有便签。
- 如果没有任何便签，启动时自动创建一个默认便签。
- 关闭便签窗口时不要让整个程序退出，除非用户从托盘菜单点击 Exit。
