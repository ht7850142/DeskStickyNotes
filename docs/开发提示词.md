# 开发提示词

这个文件记录 DeskStickyNotes 的 AI 辅助开发提示词。项目的初始代码、UI 迭代、文档和打包流程由 AI 辅助生成，并经过本地构建、打包和手动验证。

下面的提示词已经按当前公开版本整理，可作为复现或继续扩展本项目的参考。

---

请使用 C# WPF + .NET 8 开发一个 Windows 10/11 桌面便签软件。

项目名称：DeskStickyNotes

## 产品定位

做一个轻量、开源、类似 Windows 7 便签体验的 Windows 桌面便签工具。

重点不是大型笔记软件，而是：

- 桌面优先
- 普通便签不占任务栏
- 系统托盘统一管理
- 单个便签可置顶
- 可折叠为小图标
- 本地保存
- 无账号、无同步、无广告、无遥测

## 核心功能

### 1. 便签窗口

- 支持创建多个独立便签窗口。
- 便签窗口使用无标准标题栏设计。
- 顶部区域可拖动窗口。
- 窗口四边和四角都可以调整大小。
- 普通便签窗口不显示在 Windows 任务栏。
- 支持删除当前便签。
- 支持最小化当前便签到任务栏。
- 支持单个便签独立切换 Always on top。
- 支持折叠成可拖动的小图标，点击后还原。
- 折叠成图标时自动保持置顶，减少遮挡但保留提醒能力。

### 2. 编辑能力

- 内容区域使用 RichTextBox。
- 支持自动保存纯文本和富文本内容。
- 支持以下基础格式：
  - 加粗
  - 斜体
  - 下划线
  - 删除线
  - 项目符号列表
  - 编号列表
  - 待办项
  - 标题样式
  - 左对齐、居中、右对齐
  - 超链接
- 插入超链接时必须分别填写显示文字和链接地址。
- 链接地址未包含协议时，默认补全为 `https://`。

### 3. 系统托盘

- 程序启动后在系统托盘显示图标。
- 右键托盘图标显示菜单：
  - New Note
  - Show All Notes
  - Hide All Notes
  - Settings
  - Exit
- 双击托盘图标显示已有便签，不新建便签。
- 新建便签通过托盘菜单或便签标题栏 `+` 按钮完成。

### 4. 数据保存

- 自动保存所有便签。
- 保存内容包括：
  - id
  - text content
  - rich content
  - x / y position
  - width / height
  - color
  - topmost
  - visible
  - updatedAt
- 数据保存到用户 AppData 目录：
  - `%AppData%/DeskStickyNotes/notes.json`
  - `%AppData%/DeskStickyNotes/settings.json`
- 程序启动时自动恢复上次便签状态。
- 如果没有任何便签，启动时自动创建一张默认便签。

### 5. 设置界面

- 支持语言选择：
  - Auto
  - English
  - 简体中文
- 支持默认便签颜色。
- 支持默认字体大小。
- 支持开机自启。
- 支持新便签默认置顶。
- 支持 Win+D 后保持显示的尽力而为机制。
- 支持自动保存间隔。
- 显示当前版本号。

### 6. 颜色和外观

- 风格简洁，适合 Windows 11。
- 默认颜色为浅黄色。
- 支持颜色：
  - Yellow
  - Green
  - Blue
  - Pink
  - White
- 颜色按钮显示当前主题色。
- 置顶按钮使用同一个图钉图标，通过正常色和反色表示状态。
- 删除按钮使用叉号。
- 滚动条默认隐藏，不影响鼠标滚轮和键盘滚动。
- 弹出菜单和对话框应与便签整体风格一致。

### 7. Win+D 行为

- 普通窗口无法完全模拟真正的桌面组件。
- `Keep after Win+D` 只能做尽力而为。
- 可靠方案是：
  - 单个便签置顶
  - 必要时折叠成置顶小图标

## 工程要求

- 使用 WPF + .NET 8。
- 使用 MVVM 风格组织代码。
- 不依赖大型第三方框架。
- 托盘图标使用 `System.Windows.Forms.NotifyIcon`。
- JSON 序列化优先使用 `System.Text.Json`。
- 支持英文和简体中文本地化资源。
- 主要代码结构：
  - `Models/`
  - `Services/`
  - `ViewModels/`
  - `Views/`
  - `Localization/`
  - `Assets/`
- 提供 README、中文 README、CHANGELOG、LICENSE、CONTRIBUTING、SECURITY、发布说明和安装打包脚本。

## 打包要求

- 支持 framework-dependent 小安装包。
- 支持内置 .NET Desktop Runtime 的安装包。
- 支持 framework-dependent 绿色版 zip。
- 支持 self-contained 绿色版 zip。
- 使用 Inno Setup 生成安装程序。
- 安装程序支持自定义安装路径。
- 重新安装时应覆盖原程序。
- Release 包不应包含 PDB 或本机路径信息。

## 开源要求

- 项目应适合发布到 GitHub。
- `.gitignore` 必须排除：
  - `bin/`
  - `obj/`
  - `artifacts/`
  - `.vs/`
  - `.env`
  - 证书和密钥文件
  - 本地 runtime 安装包
- 不提交真实用户便签数据。
- 不提交打包产物到源码仓库。
- 安装包和绿色版 zip 应作为 GitHub Releases 附件上传。
