# 开发提示词

适用版本：**DeskStickyNotes 0.6.0**。最后整理：2026-11-06。

本文件是随项目维护的 AI 辅助开发规格，用于复现当前产品或继续迭代，并非原始对话的逐字记录。历史版本可在 Git 历史中查看；实际功能以源码和 [CHANGELOG](../CHANGELOG.md) 为准。

项目已进行 Release 构建、打包、27 项自动回归检查及示例界面渲染检查。完整 Explorer/Win+D、多显示器手动操作和安装升级仍需在真实 Windows 会话中验收，不能将自动检查描述为这些场景已经人工实测。

---

请使用 **C#、WPF 和 .NET 8** 开发并维护一个 Windows 10/11 x64 桌面便签软件，项目名称为 **DeskStickyNotes**。

## 产品定位

延续 Windows 7 便签随手记录、常驻桌面的使用方式，采用适合 Windows 10/11 的轻纸张界面。让用户快速记下内容、查看提醒，并通过键盘或托盘在多个便签之间切换。

- 多张独立便签，普通状态不占任务栏。
- 单便签置顶、折叠小图标、托盘管理和全局快捷键。
- 纯文本、基础富文本、图片及长文本切片。
- 本地保存，无账号、云同步、广告、遥测或应用内网络功能。
- 控制依赖规模，保持原生 Windows 操作习惯。

## 1. 便签窗口与交互

- 使用无标准标题栏的 WPF 窗口，默认尺寸 390 × 300，最小尺寸 300 × 180。
- 标题栏保留新建、颜色、置顶、折叠和更多操作；更多菜单提供改名、最小化到任务栏和删除。
- 单击标题栏保持展开，拖动可移动，双击或按 F2 改名。标题最长 80 个 UTF-16 代码单元，截断时不拆开代理对；空标题显示本地化默认名称。
- 四边和四角均可调整大小，空白便签也应保存用户设定的尺寸。缩放时由 WPF 调度布局，避免每次鼠标移动都强制同步布局。
- 正常便签不显示任务栏按钮；主动最小化时允许进入任务栏。托盘隐藏与主动最小化应分别处理。
- 每张便签独立保存置顶偏好。图钉按钮需有清晰的选中状态和可访问名称。
- 独立折叠按钮将便签变成可拖动的置顶提醒图标；单击、Enter 或空格还原。折叠期间的置顶不可改写保存的置顶偏好。
- 折叠和还原保持原窗口尺寸与图标锚点；启动、屏幕边缘展开及显示器/DPI 变化时，使窗口落在所在显示器的可用区域内。

## 2. 编辑、图片与文本切片

- 使用 RichTextBox，自动保存富文本和纯文本回退内容。
- 支持加粗、斜体、下划线、删除线、项目符号、编号、待办项、标题、左/中/右对齐和超链接。
- 格式工具按功能分组，小窗口时整组换行；显示当前选区的文字格式和对齐状态。
- 空白便签显示简短输入提示；长内容按需显示滚动条，并保留鼠标滚轮和键盘滚动。
- 超链接对话框分别填写显示文字与地址；缺少协议时补 `https://`。
- 支持粘贴图片，自动适应可用宽度；支持拖动边角、Ctrl + 滚轮和右键菜单调整图片尺寸，并随富文本保存。
- 选中文字可收纳为可点击的长文本切片；剪贴板内容可从切片菜单或 `Ctrl+Shift+V` 导入。
- 支持拖入、粘贴文件或通过文件选择器导入常见文本、Markdown、JSON、CSV、日志和源代码文件。
- 导入时识别支持的 Unicode 和常见中文编码，拒绝二进制、非支持格式和超限文件；单个文本切片最多 2 MB，单张便签切片总量最多 8 MB、最多 200 个。
- 文本切片保存内容快照及来源信息，源文件移动或删除后仍可预览。预览窗口支持滚动、自动换行和复制全文。

## 3. 桌面层级与 Win+D

- `Keep after Win+D` 是尽力而为的 Windows Shell 兼容行为，不承诺普通窗口在所有情况下等同于桌面组件。
- 禁止每张便签各自通过高频定时器不断置顶；多个重叠窗口不能因相互争抢层级而闪烁。
- 使用应用级协调器统一恢复，合并重复通知，按最近激活顺序从后向前处理，并分别保持正常窗口与置顶窗口的层级分组。
- 当前实现使用单个 250 ms 后台检查器，仅在桌面进入或实际隐藏/最小化抑制等条件下恢复；桌面空闲时不能持续写入窗口层级。
- 恢复不抢键盘焦点，忽略自身恢复引起的通知，抑制恢复最多重试 3 次。
- 排除用户主动隐藏、主动最小化、关闭桌面恢复的便签；其他虚拟桌面的 cloaking 不能单独触发恢复。
- 为重叠置顶便签和置顶/普通混合便签提供回归检查，并保留真实 Explorer/Win+D 会话验收步骤。

## 4. 可自定义的全局快捷键

| 操作 | 默认组合 |
| --- | --- |
| 新建并编辑便签 | `Ctrl+Alt+N` |
| 切换到下一张便签 | `Ctrl+Alt+PageDown` |

- 程序在后台运行时也可使用，按住按键不应重复生成便签。
- 循环切换按便签创建顺序进行，包括隐藏、最小化和折叠的目标；唤出后聚焦便签内容。
- 非置顶便签被其他置顶便签覆盖时，可临时提到上方供操作，失去激活后恢复其保存的置顶偏好。
- 设置中直接录入组合键，须包含 Ctrl、Alt 或 Win，可再加 Shift；支持清空停用、单独清除和恢复两组默认值。
- 录入期间暂停全局注册，离开录入框或关闭窗口时恢复；保留 Tab/Shift+Tab 焦点导航和 Escape 离开录入的操作。
- 使用消息窗口、`RegisterHotKey`、`WM_HOTKEY` 和 `MOD_NOREPEAT`，不依赖全局键盘钩子或模拟按键。
- 保存时检查非法组合、重复和系统占用。先保留新组合，再释放旧组合；失败回滚，原来可用的绑定继续工作，交换两个操作的组合键也应成立。
- 启动时一个快捷键被占用不能导致另一个可用快捷键失效；通过本地化提示告知占用，退出时释放所有注册。

## 5. 系统托盘与图标

- 使用 `System.Windows.Forms.NotifyIcon`，普通便签窗口关闭或隐藏时保持程序运行。
- 菜单包含新建、便签列表、显示全部、隐藏全部、设置和退出；双击托盘图标显示已有便签。
- 展示便签总数与可见数，便签列表反映名称和可见状态，可独立显示或隐藏每张便签。
- 托盘菜单使用统一图标、间距和悬停状态，保留原生键盘导航；高对比度模式使用系统渲染。
- 应用图标、折叠图标和设置页沿用同一可编辑矢量母版；为通知区域提供简化的小尺寸图标。
- 维护多分辨率 ICO：托盘覆盖 16–64 像素，应用图标另外包含 128、256 像素；检查深浅色任务栏背景。

## 6. 设置与视觉规范

- 保持浅纸张、深墨文字和柔和绿色强调色的视觉方向，提供浅黄、浅绿、浅蓝、浅粉、白色五种便签配色。
- 单张便签背景透明度支持 30%–100%，不连带降低文字、控件或图片的不透明度；文字支持自动、深色和浅色模式。
- 设置按外观、全局快捷键、桌面与启动、保存分组；主内容可滚动，保存/取消栏固定，适应较小屏幕和高 DPI。
- 色块选择和字号滑块更新示例预览；界面明确说明颜色/默认置顶影响新便签，字号会应用到所有便签。
- 支持跟随系统的语言选择、默认颜色、字号 10–28、开机自启、新便签默认置顶、Win+D 恢复、自动保存间隔 1–60 秒及版本显示。
- 设置编辑草稿，保存后才应用，取消或 Escape 不提交；快捷键错误显示在固定操作栏上方，保持窗口打开供修正。
- 使用清晰的焦点、悬停、禁用和选中状态，以及按钮/录入框的可访问名称。弹出菜单与对话框沿用同一套主题资源。

## 7. 七种语言

| 选项 | 资源代码 |
| --- | --- |
| 跟随系统 | `Auto` |
| 简体中文 | `zh-Hans` |
| 繁體中文 | `zh-Hant` |
| English | `en-US` |
| Français | `fr-FR` |
| Español | `es-ES` |
| Português | `pt-PT` |
| 日本語 | `ja-JP` |

- 每种语言提供完整资源，覆盖设置、托盘、编辑提示和对话框，资源键与格式化占位符一致。
- Auto 根据程序启动时的系统 UI 语言判断，不受此前手动切换所改写的线程语言影响。
- 区分简繁中文和台湾/香港/澳门等地区；法语、西语、葡语地区变体映射到已有翻译，其他未支持语言回退英文。
- 界面按语言更新字体和文本语言：简体中文用 Microsoft YaHei UI、繁体中文用 Microsoft JhengHei UI、日语用 Yu Gothic UI，其他用 Segoe UI 并提供回退。
- 保存语言设置后更新已打开界面和托盘；检查长译文换行、底部操作可见性及错误提示布局。

## 8. 本地数据与兼容

- 数据保存在 `%AppData%/DeskStickyNotes/notes.json` 和 `%AppData%/DeskStickyNotes/settings.json`，安装版与绿色版沿用同一数据位置。
- 便签保存独立 id、标题、纯文本、富文本、文本切片、位置、尺寸、颜色、背景透明度、文字模式、置顶偏好、可见性和更新时间。
- 启动恢复已有便签，没有任何便签时创建默认便签；明确区分保存的用户偏好和临时窗口状态。
- 使用 `System.Text.Json` 和临时文件替换写入，加载时规范化非法尺寸、颜色和设置值。
- 保留旧版本的设置迁移。schema 4 新增快捷键：缺失或 null 使用默认值，显式空字符串保持停用。
- 覆盖安装不清除 AppData。演示、测试、截图不得读取或修改真实便签，不把凭据或私人内容放入样例。

## 9. 工程与验证

- MVVM 风格，主要目录为 `Models/`、`Services/`、`ViewModels/`、`Views/`、`Localization/`、`Themes/`、`Assets/`，不引入大型 UI 框架。
- 统一在主题资源中维护组件状态与样式，在独立服务中处理存储、托盘、自启、桌面恢复、快捷键和本地化。
- 开机自启通过当前用户 Run 注册表项实现，不要求管理员权限。
- 提供英文/中文 README、CHANGELOG、LICENSE、CONTRIBUTING、SECURITY、架构与发布指南。
- 回归检查使用隔离临时目录，覆盖几何、尺寸与名称保存、文本编码与快照、托盘、设置草稿、桌面恢复策略、原生窗口层级、快捷键及全部语言的资源/布局。
- 示例预览从编译后的真实 WPF 控件渲染，标明示例内容，不伪称为桌面实机截图。文档截图随界面更新。

## 10. 打包与开源发布

- 使用 Inno Setup，支持自定义安装路径和覆盖旧版本。
- 提供 framework-dependent 小安装包、内置 .NET Desktop Runtime 的安装包、framework-dependent 绿色 ZIP、自包含绿色 ZIP 四个包。
- 当前 0.6.0 运行时为 .NET Desktop Runtime 8.0.31；从微软元数据下载，并校验官方 SHA-512。
- 所有程序包生成 SHA-256 校验清单，不包含 PDB、便签数据或构建调试路径。
- 打包输出按版本隔离，避免覆盖其他版本的临时发布目录。
- `.gitignore` 排除 bin、obj、artifacts、IDE 缓存、环境文件、证书密钥、本地运行时安装器；程序包作为 GitHub Release 附件，不能进入源码历史。
- 先提交并推送源码，通过构建与检查，再基于确切提交打包和创建草稿 Release。上传并核对四个包和校验清单后公开，发布说明包含更新、安装选择、数据兼容及验证范围。
- 文档单独更新可以继续提交至主分支；已有版本标签和程序附件保持对应原发布提交，应用行为未变时无需重打包。

```powershell
./scripts/package.ps1 -AllInstallers
```
