## Capture Tips

- Use Windows 11 with 100% or 125% scaling.
- Use a clean desktop background.
- Avoid private note content, personal file names, browser tabs, and account information.
- Keep text realistic but generic: todo lists, quick ideas, meeting notes, or short links.
- Prefer PNG for README images.
- Keep screenshots under about 1 MB each when possible.

## README Placement

The README should prioritize:

1. Main note window
2. Collapsed icon mode
3. Settings or tray menu once recaptured for the current version

Use descriptive alt text, for example:

```markdown
![DeskStickyNotes Win7-style sticky note on Windows 11](docs/images/note-window.png)
```

## Product Strengths To Show Visually

- Notes can stay visible above other windows.
- Collapsed icon mode keeps a topmost note available without taking much space.
- Notes stay out of the taskbar.
- The tray menu is the control center.
- The UI is simple and native.
- Notes are local-first and do not require an account.
- Collapsed icon mode makes always-on-top notes less intrusive.
