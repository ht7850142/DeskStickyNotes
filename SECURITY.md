# Security Policy

DeskStickyNotes is a local desktop app. It does not provide accounts, sync, cloud storage, telemetry, or analytics.

## Supported Versions

Security fixes are handled for the latest public release.

## Reporting A Vulnerability

If the repository is hosted on GitHub, please use GitHub Security Advisories when available.

If private reporting is not available, open an issue with a minimal description and avoid posting sensitive data, private note content, or exploit details. The maintainer can then coordinate a safer disclosure path.

## Local Data

User data is stored locally:

```text
%AppData%\DeskStickyNotes\notes.json
%AppData%\DeskStickyNotes\settings.json
```

When sharing logs, screenshots, or JSON files, remove private note content first.
